# 제5회 대학 연합 아주 소중한 딥러닝 챌린지 2026

범용 언어 모델 `Qwen/Qwen2.5-3B-Instruct`를 미세 조정해 처음 보는 수학 문제의 정수 답을 정확히 추론하는 모델을 개발하는 대회입니다.

## 대회 정보

| 항목 | 내용 |
|---|---|
| 주제 | LLM을 활용한 수학 문제 해결 |
| 주최 | 아주대학교 AI융합교육원(SW중심대학사업) |
| 참여 대학 | 아주대학교, 경북대학교, 경희대학교, 부산대학교, 전남대학교, 전북대학교 |
| 베이스 모델 | [`Qwen/Qwen2.5-3B-Instruct`](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct) |
| 평가 지표 | Accuracy (Exact Match) |
| 최종 순위 | Private Leaderboard 점수 기준 |

## 참가 자격

- 참여 6개 대학 소속 학부생만 참가할 수 있습니다.
- 2026학년도 1학기 기준 휴학생도 참가할 수 있습니다.
- 개인 또는 팀으로 참가할 수 있으며, 한 사람이 여러 팀에 소속될 수 없습니다.
- 상금은 지급 시점인 2026학년도 2학기에 재학 중인 학생에게만 지급됩니다.

시간대와 변경된 일정은 대회 최신 공지를 기준으로 확인해야 합니다.

## 평가 및 제출

- Public Leaderboard는 테스트 데이터의 30%를 사용하며 대회 중 참고용으로 제공됩니다.
- Private Leaderboard는 나머지 70%를 사용하며 공식 순위를 결정합니다.
- 정답은 정수이며 제출값과 정확히 일치해야 정답으로 인정됩니다.
- `submission.csv`에는 모든 문제의 `ID`와 정수형 `answer`를 포함해야 합니다.
- 최종 발표 대상 12팀(명)은 모델 성능 50%와 발표 평가 50%를 합산해 검증하며, 최종 9팀(명)을 수상자로 선정합니다.

## 주요 규칙

- 지정된 베이스 모델만 사용할 수 있으며, 다른 모델의 가중치를 불러오거나 병합할 수 없습니다.
- Full Fine-Tuning, LoRA·QLoRA, SFT, RL 기반 학습, 데이터 증강, 커리큘럼 학습과 양자화를 사용할 수 있습니다.
- 추론 중 인터넷, 외부 API, 웹 검색 및 다른 외부 모델 호출은 금지됩니다.
- 추론 중 모델이 생성한 코드를 실행하거나 Python·SymPy·사전 작성 계산 함수 등 외부 코드·도구를 호출해서는 안 됩니다.
- Majority Voting, Self-Consistency와 외부 계산 도구 없이 모델 출력만 사용하는 Best-of-N 등의 테스트 타임 기법은 사용할 수 있습니다.
- 수상 후보자는 코드, 모델 가중치, 데이터셋 목록, 실행 환경과 방법론 문서를 제출해야 하며 재현 검증을 통과해야 합니다.
