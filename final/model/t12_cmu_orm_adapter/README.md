# T12 CMU ORM adapter

This directory contains the trained component specific to the T12 submission.
It is a rank-64 PEFT LoRA adapter for a one-label sequence classifier, including
the saved scalar score head.

It is **not a standalone model**. Load it with:

- base model: `Qwen/Qwen2.5-3B-Instruct`
- revision: `aa8e72537993ba99e69dfaafa59ed015b17504d1`
- `AutoModelForSequenceClassification(num_labels=1)`
- `PeftModel.from_pretrained(...)`

The inference pipeline verifies the SHA-256 of `adapter_model.safetensors` before
using it. Candidate solutions are generated by the unmodified base causal LM;
this adapter is used only to score those solutions.
