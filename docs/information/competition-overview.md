# 대회 개요

## 목적

수학에 특화되지 않은 범용 모델 `Qwen/Qwen2.5-3B-Instruct`를 출발점으로 삼아, 처음 보는 수학 문제의 **정수 답을 정확히 추론하는 모델**을 만드는 대회입니다. LLM의 수학적 추론 한계를 탐색하고 학습 전략을 발굴하는 것이 목적입니다.

- 참여 6개 대학 소속 **학부생**만 참가할 수 있습니다.
- 2026-1학기 기준 휴학생도 참가할 수 있습니다.
- 문제 공개 후 자체 또는 그룹 스터디를 통한 자기주도학습이 가능한 학생을 대상으로 합니다.
- 주최 기관 운영진은 참가할 수 없습니다.
- 상금은 지급 시점인 2026-2학기에 재학생인 경우에만 지급됩니다. 8월 졸업자, 학사취득유예자, 휴학생 등은 상금 지급 대상이 아닙니다.
