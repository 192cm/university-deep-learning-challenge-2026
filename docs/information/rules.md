# 모델·데이터·추론 규칙

## 베이스 모델

- 유일한 출발점은 `Qwen/Qwen2.5-3B-Instruct`입니다.
- Qwen2.5-Math, DeepSeek-R1, Llama, GPT 등 다른 모델을 베이스로 사용하면 안 됩니다.
- 다른 모델의 가중치를 불러오거나 병합하는 행위도 금지됩니다.
- 사전 학습을 처음부터 수행하는 것은 금지되며 fine-tuning만 허용됩니다.

## 허용되는 학습 기법

- Full Fine-Tuning
- LoRA, QLoRA 등 PEFT
- SFT(Supervised Fine-Tuning)
- GRPO, DPO, PPO, KTO 등 RL 기반 학습
- 데이터 증강과 커리큘럼 학습
- 양자화

## 추론 규칙

- 인터넷 접속, 외부 API 호출, 웹 검색은 금지됩니다.
- 모든 추론은 제공된 환경에서 로컬로 수행해야 합니다.
- 다른 외부 모델을 호출해 앙상블하면 안 됩니다.
- Majority Voting, Self-Consistency, Best-of-N 등 테스트 타임 기법은 자유롭게 사용할 수 있습니다.

### 코드 실행·도구 호출에 대한 운영진 답변

2026-08-01 Discord에서 운영진은 **추론 시 모델의 추론 출력만으로 답을 도출해야 하며, 코드 실행과 도구 호출은 허용하지 않는다**고 답변했습니다. 이에 따라 다음 방식은 금지됩니다.

- 모델이 생성한 Python 코드를 로컬 샌드박스에서 실행하고 그 결과를 다시 모델에 입력하는 TIR(Tool-Integrated Reasoning)·Program-of-Thought
- 참가자가 미리 작성한 방정식 풀이, 소인수분해, 최대공약수 계산 등의 함수를 모델이 호출하는 방식
- Python, SymPy, SAT/수치 해석기 또는 결정론적 계산 verifier로 후보 답을 계산·수정·선택하는 방식

다음은 운영진이 명시적으로 허용한 다중 샘플링과 그 결과를 제출 답으로 만드는 데 필요한 비수학적 처리의 보수적인 범위로 해석할 수 있습니다.

- 모델 응답을 여러 개 생성하는 Majority Voting과 Self-Consistency
- 모델 출력에서 최종 답을 추출하고 같은 표현으로 정규화해 투표하는 처리
- 답의 일치도만을 기준으로 추가 샘플 생성 여부를 결정하는 adaptive sampling과 early stopping
- 제출 파일의 형식, 행 수, ID 중복·누락을 확인하는 비수학적 검증

Best-of-N도 후보 생성과 선택이 모델 출력만으로 이루어져야 하며, 금지된 계산기·solver·코드 verifier를 선택 기준으로 사용할 수 없습니다. 답 추출 코드는 모델이 이미 출력한 답을 형식적으로 읽는 데만 사용해야 하며, 계산을 수행해 답을 교정해서는 안 됩니다. 문제별 BM25·embedding 검색처럼 테스트 문항에 따라 외부 정보를 동적으로 프롬프트에 넣는 retrieval은 이 답변에서 명시적으로 다뤄지지 않았지만, "모델의 추론 출력만으로 답을 도출"한다는 원칙과 충돌할 가능성이 있으므로 추가 허용 답변을 받기 전에는 테스트 타임에 사용하지 않는 것이 안전합니다.

이 제한은 추론 단계에 대한 답변입니다. 학습 데이터 구축 과정의 자동 계산 검증과 풀이 생성은 [데이터 사용 조건](data.md#데이터-사용-조건)을 따르되, 그 코드나 도구를 테스트 문제에 적용하거나 추론 결과로 되먹임해서는 안 됩니다.

## 팀 규칙

- 개인 또는 팀으로 참가할 수 있습니다.
- 한 사람이 여러 팀에 소속될 수 없습니다.
- 참여 6개 대학 소속 학부생이라면 서로 다른 대학 학생끼리도 팀을 구성할 수 있습니다.
- Kaggle 기본 규칙에 따라 개인은 하나의 Kaggle 계정만 사용해야 하며, 팀 외부에서 대회 코드나 데이터를 비공개로 공유하면 안 됩니다.

## 수상 후보자의 재현 의무

수상 후보자는 다음 자료를 제출해야 합니다.

- 학습 코드와 추론 코드
- 학습된 모델 가중치
- 사용 데이터셋 목록 및 접근 방법
- 하드웨어와 라이브러리 버전 등 실행 환경 설명
- 아키텍처, 전처리, 학습 세부사항, 하이퍼파라미터 등을 포함한 방법론 문서

주최 측의 재현 검증에 실패하면 수상이 취소될 수 있습니다.

## 부정행위와 제재

다음은 부정행위로 간주되며 실격 및 수상 자격 박탈의 사유가 됩니다.

- 테스트 정답을 외부에서 확보해 제출
- 다른 참가자의 코드·모델·제출물을 무단 사용
- 여러 계정으로 제출 횟수 제한 우회
- 리더보드 점수로 정답 역추적(probing)
- 규칙을 의도적으로 우회

## 지적 재산권과 규칙 변경

- 참가자가 작성한 코드와 모델의 지적 재산권은 참가자에게 귀속됩니다.
- 주최 측은 결과 발표와 홍보를 위해 참가자의 방법론 요약을 활용할 수 있습니다.
- 주최 측은 대회 중 규칙을 변경할 수 있으며 공지로 안내합니다. 변경 전 제출물에는 소급 적용하지 않습니다.
- 대회별 규칙과 Kaggle 기본 규칙이 충돌하면 Kaggle 기본 규칙이 우선합니다.
